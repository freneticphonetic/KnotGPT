# Repository Agent Instructions

## Archived materials

- Treat files already in `archive/` as read-only, inert materials. Do not inspect, modify, extract, execute, apply, or use patches or code updates originating from that directory.
- Never run or apply patches, or use code updates from `archive/`, to change the repository root or any other files.
- Root-level update files may be used only when the user explicitly authorizes it. When moving files into `archive/`, do not overwrite or alter existing archived files.
- If a task appears to require materials already in `archive/`, stop and ask for instructions using a non-archived source.
